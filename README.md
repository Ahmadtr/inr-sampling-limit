# Sampling-dependent limits on the frequency scale of sinusoidal INRs

Code and raw results for the paper

> A. S. Tarawneh, *Sampling-dependent limits on the frequency scale of sinusoidal implicit neural representations* (under review).

The paper measures how large the first-layer frequency scale ω₀ of a sinusoidal implicit neural representation
(SIREN, FINER, FINER-Grad, Harmonic, PM-FINER, SMN) can be before the network stops generalising **between** its
training samples. The limit scales with the sample spacing Δ, ω₀^max·Δ ≈ c_m, with one constant c_m per activation.
The calibrated rule **ω₀ = c_m / (4Δ)** needs no per-signal search.

## Calibrated constants (images, 3 hidden layers × 256, step schedule)

| Activation | c_m  | ω₀ at stride 8 | ω₀ at stride 16 |
|------------|------|----------------|-----------------|
| SIREN      | 3.12 | 12.4 | 6.2 |
| FINER      | 1.52 | 6.1  | 3.0 |
| FINER-Grad | 1.50 | 6.0  | 3.0 |
| PM-FINER   | 1.80 | 7.2  | 3.6 |

Δ = 2·stride/255 for a 256×256 image with pixel coordinates in [-1, 1]. For a different network or training setup, re-estimate c_m (see `code/test8_images_2d.py`).

## Layout

```
code/       experiment scripts (each one writes results/<test>_*.json, resumable)
analysis/   scripts that turn results/ into the tables and figures of the paper
results/    raw results of every experiment in the paper
figures/    figures of the paper (regenerated by analysis/)
data/       put the Kodak images here (see data/README.md)
```

The scripts expect two repositories next to `code/`:

```bash
git clone https://github.com/Ahmadtr/harmonic-pmfiner-inr   # published networks (SIREN, FINER, ..., SMN) and test images
git clone https://github.com/gmum/FreSh                      # original FreSh code (only for code/test13_kodak_fm_fresh.py)
pip install -r requirements.txt
```

## Reproducing the paper

Tables and figures from the stored results (no GPU needed):

```bash
python analysis/final_analysis.py    # Tables 1, 2, 4, 5 (1D and image limits, constants, rule vs default)
python analysis/round2_analysis.py   # Table 3 (first robustness runs) and Table 7 (Kodak baselines, paired tests)
python analysis/round3_analysis.py   # Table 3 (jittered/random sampling, learning-rate check) and Table 8 (original FreSh, FM-SIREN/FM-FINER)
python analysis/make_figures.py      # Figures 1-4 (files fig1, fig4, fig2, fig3 = paper Figs. 1, 2, 3, 4)
python analysis/make_fig5.py         # Figure 5 and Appendix figures
```

Re-running the experiments (GPU recommended; 5000 full-batch epochs per training):

| Paper | Script | Command (from `code/`) |
|-------|--------|------------------------|
| Fig. 1, Table 1, Table 2 (step) | `test7c_methods_1d.py` | `python test7c_methods_1d.py --sched step --methods SIREN,FINER` (likewise for the other methods) |
| Table 2 (cosine) | `test7c_methods_1d.py` | `python test7c_methods_1d.py --sched cosine --methods SIREN,FINER` |
| Table 2 (no schedule) | `test7b_methods_1d.py` | `python test7b_methods_1d.py --methods SIREN,FINER` |
| Fig. 2 | `test11_recon1d.py` | `python test11_recon1d.py` |
| Table 3 (robustness) | `test12_1d_variants.py` | e.g. `python test12_1d_variants.py --tag clean --noise 0 --methods SIREN,FINER`; options `--hidden --layers --sampling {uniform,random,jitter} --g0 --lr`, e.g. `--tag w512lr5 --hidden 512 --lr 5e-5`, `--tag jitter --sampling jitter --jitter 0.5 --g0 0.25` |
| Fig. 3, Table 4 (image limits) | `test8_images_2d.py` | `python test8_images_2d.py --tag test8b --sched best --images bike,parrot,astronaut --strides 2,3,4,6,8 --nvals 14 --gmin 6 --gmax 800 --methods SIREN` |
| Fig. 4, Tables 5, 6 (rule on held-out images) | `test9_practical.py` | `python test9_practical.py --methods FINER` |
| Table 7, Fig. 5 (Kodak: default, rule, FreSh-style, validation search) | `test10_kodak_baselines.py` | `python test10_kodak_baselines.py --methods FINER` |
| Table 8 (Kodak: original FreSh, FM-SIREN / FM-FINER) | `test13_kodak_fm_fresh.py` | `python test13_kodak_fm_fresh.py --methods FINER` |
| WIRE check on the full image | `check_wire_repro.py`, `check_wire2.py` | `python check_wire_repro.py` |

The limit is computed with one measure everywhere (`code/unified_cliff.py`): the smallest ω₀ above the best value after which
the extra held-out error stays above τ·Var(signal), τ = 0.05.

`test2`–`test6` are the preliminary experiments that led to the final protocol (held-out evaluation, choice of the limit
measure, band-limited 2D check). They are kept for completeness; the paper's tables do not depend on them.

## Notes

* Only the **first** layer's ω₀ is changed; hidden layers keep the published defaults of each activation.
* FM-SIREN / FM-FINER and the FreSh-style selection of `test10` are our implementations from the papers' descriptions;
  `test13` uses the original FreSh spectrum code.
* Results were produced on one NVIDIA GPU with PyTorch; small numerical differences between machines are expected.
